1 // cxpm-descriptor-sandbox: a small, single-purpose helper process. Its only job is to dlopen a
2 // shared object compiled from a package.cpp/toolchain.cpp, call its generated get_project()/
3 // get_toolchain() getter, and print the resulting descriptor as compact JSON on stdout.
4 //
5 // It exists so that CXPM::Controllers::DescriptorSandbox (see
6 // CXPM/Controllers/DescriptorSandbox.hpp) never has to dlopen a package.cpp/toolchain.cpp's
7 // compiled output directly inside the main cxpm process. That code was compiled moments earlier
8 // from a project- or dependency-authored .cpp file; its static initializers run with whatever
9 // privileges this process has the instant dlopen() returns. Isolating that step in a disposable
10 // child process bounded by rlimits and a wall-clock alarm keeps a buggy or malicious
11 // package.cpp/toolchain.cpp from being able to do anything to the actual `cxpm` process's memory,
12 // file descriptors, or exit code beyond what this file's stdout/exit-code contract allows.
