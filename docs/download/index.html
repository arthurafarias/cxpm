cxpm /Download

Download

cxpm is prebuilt for x86_64 as a package for each of the main Linux package managers, and published on the release page of github.com/arthurafarias/cxpm . The current release is 0.3.0. The handbook you are reading explains what the command does; the CLI Reference has the full text of cxpm help for every command.

Every distribution installs the same packages, and the package manager orders them:

PackageWhat it is
cxThe cx libraries cxpm is built with: headers and pkg-config files
cxpm-interfaceThe headers a package.cpp includes, <cx/pm/project.hpp> and <cx/pm/target.hpp>
cxpm-descriptor-sandboxThe helper that compiles and loads a manifest in a confined process
cxpm-toolchain-gcc, -g++, -clang, -clang++, -nvccThe toolchain modules: the ones for the compilers you have, g++ at least
cxpmThe command

A C++23 compiler (g++ 14, clang++ 18 or newer), git and pkg-config have to be on the machine; cxpm finds them on PATH. Each release carries one tar bundle per format with every package in it, and the single packages beside it.

Arch Linux, Manjaro

curl -fsSLO https://github.com/arthurafarias/cxpm/releases/download/v0.3.0/cxpm-0.3.0-arch-x86_64.tar
tar -xf cxpm-0.3.0-arch-x86_64.tar
sudo pacman -U --needed cxpm-0.3.0-arch-x86_64/*.pkg.tar.zst

Built on Arch Linux with cxpm-build.sh --package-manager pacman. Arch’s libxpm installs the XPM checker of libXpm as /usr/bin/cxpm, the file the cxpm package installs; the bundle carries a rebuilt libxpm (3.5.20-1.1, its PKGBUILD is in the public repository under packaging/arch/libxpm) that installs that tool as xpm and is otherwise the Arch package. It replaces the installed libxpm, and the rest installs without conflict. A later libxpm from the repositories brings /usr/bin/cxpm back and pacman refuses the upgrade with a file conflict: rebuild the PKGBUILD against the new version, or add libxpm to IgnorePkg.

Debian 13, Ubuntu 24.04 and later

curl -fsSLO https://github.com/arthurafarias/cxpm/releases/download/v0.3.0/cxpm-0.3.0-debian-amd64.tar
tar -xf cxpm-0.3.0-debian-amd64.tar
sudo apt install ./cxpm-0.3.0-debian-amd64/*.deb

Built on Debian 13 (trixie) with its g++ 14; the packages install on any Debian or Ubuntu whose glibc and libstdc++ are at least trixie’s (Ubuntu 24.04 and later).

Fedora, RHEL 9 and 10, Amazon Linux 2023

curl -fsSLO https://github.com/arthurafarias/cxpm/releases/download/v0.3.0/cxpm-0.3.0-rpm-x86_64.tar
tar -xf cxpm-0.3.0-rpm-x86_64.tar
sudo dnf install ./cxpm-0.3.0-rpm-x86_64/*.rpm

Built on Fedora with cxpm-build.sh --package-manager rpm.

Then

cxpm help                           # the commands; cxpm help <command> describes one
cxpm project create greeter --type static-library --tests --example
cd greeter && cxpm build && cxpm test

The quickstart goes on from here.

Removing

sudo pacman -Rs cxpm cxpm-toolchain-gcc cxpm-toolchain-g++ cxpm-toolchain-clang cxpm-toolchain-clang++ cxpm-toolchain-nvcc cxpm-descriptor-sandbox cxpm-interface cx
sudo apt remove  cxpm cxpm-toolchain-gcc cxpm-toolchain-g++ cxpm-toolchain-clang cxpm-toolchain-clang++ cxpm-toolchain-nvcc cxpm-descriptor-sandbox cxpm-interface cx
sudo dnf remove  cxpm cxpm-toolchain-gcc cxpm-toolchain-g++ cxpm-toolchain-clang cxpm-toolchain-clang++ cxpm-toolchain-nvcc cxpm-descriptor-sandbox cxpm-interface cx

From source

The source of cxpm is not public: it is built on the cx libraries, which are closed source. The public repository holds the packages, the readme and the command line reference.
